# Premium UI Skill

The product is meant to feel like a high-end SaaS tool — closer to Linear, Vercel, Arc, Stripe, or Rauno's portfolio than a Bootstrap template or a "generated by AI" landing page. Restraint, intention, and craft over decoration.

## Core principles

1. **Restraint over decoration.** White space carries the design. If a section feels empty, the answer is usually larger type and tighter copy, not more elements.
2. **One focal point per view.** Every screen has a single hero element. Everything else is supporting.
3. **Typography does the heavy lifting.** Most "luxury" feeling comes from type scale, weight contrast, and tracking — not gradients or shadows.
4. **Motion is functional, not ornamental.** Animation signals state and hierarchy. Never animate something that doesn't need it.
5. **Mobile-first, always.** Design the 375px view first, then expand. Touch targets ≥44px, no hover-only affordances.

## Aesthetic vocabulary

- **Palette:** near-black ink (`#0b0b0f`), warm whites (`#f7f7f8`), and a single restrained accent (`gold-400` `#d4be7a` in this codebase). No rainbow gradients. No purple-to-pink. No neon.
- **Surfaces:** flat, occasionally with a `shadow-soft` or `shadow-elevated` lift. Borders are `1px ink-100`, never heavier.
- **Imagery:** editorial, high-contrast, lots of negative space. If using illustration, keep it monochrome or duotone.
- **Corners:** `rounded-md` (12px) for cards, `rounded-sm` (8px) for inputs, `rounded-xs` (4px) for chips. Avoid `rounded-full` except on avatars and pills.

## Typography hierarchy

Defined in `tailwind.config.ts`. Use the semantic class — do not hand-roll `text-[44px]`.

| Token | Use for |
|---|---|
| `text-display-xl` (72px) | Marketing hero on lg+ only |
| `text-display-lg` (56px) | Section heroes, pricing headline |
| `text-display-md` (44px) | Mobile hero, large feature headers |
| `text-h1` (36px) | Page titles in-app |
| `text-h2` (28px) | Section headings |
| `text-h3` (22px) | Card titles, subsections |
| `text-body-lg` (18px) | Lede paragraph, marketing body |
| `text-body` (16px) | Default body |
| `text-body-sm` (14px) | Metadata, secondary copy |
| `text-caption` (12px, uppercase, tracked) | Eyebrows, labels, badges |

**Rules**

- Display sizes use the serif `font-display` (Playfair). Everything else is `font-sans` (Inter).
- Headlines: tight tracking (`-0.02em`+ is baked into the token), weight 600 max. Avoid weight 700+ — it reads cheap at large sizes.
- Body copy: weight 400, line-height 1.6, never wider than `max-w-2xl` (~65ch).
- Use sentence case for headlines. Title Case only for nav labels and CTAs.
- Pair exactly two typefaces. Never three.

## 8px spacing system

The Tailwind spacing scale in this project is rewired to 8px increments. `p-1` = 8px, `p-2` = 16px, `p-3` = 24px, etc. The only sub-8 value is `0.5` (4px), reserved for icon gaps and chip insets.

**Rules**

- Every gap, padding, and margin must resolve to a token from the scale. No `p-[10px]`, no `gap-[18px]`.
- Component internal padding: `p-2` (16px) for compact, `p-3` (24px) for default, `p-4`–`p-6` for cards and hero sections.
- Vertical rhythm between sections: `py-8` (64px) on mobile, `py-12` (96px) on tablet, `py-16` (128px) on desktop.
- Stack spacing inside a section: `space-y-2` (16px) for tight, `space-y-3` (24px) default, `space-y-4` (32px) airy.
- Grid gaps: `gap-2` for dense data, `gap-3` for cards, `gap-4`+ for hero layouts.

## Framer Motion

One easing curve, three durations. Consistency is the point.

```ts
const ease = [0.16, 1, 0.3, 1]; // also available as `ease-luxe` in Tailwind
const durations = { fast: 0.2, base: 0.4, slow: 0.7 };
```

**Patterns**

- **Entrance:** `opacity: 0 → 1`, `y: 16 → 0`, duration `0.7`. Stagger children by `0.06`–`0.08`s.
- **Hover lift:** `y: 0 → -2`, `scale: 1 → 1.01`, duration `0.2`. Never scale above `1.03`.
- **Press:** `scale: 1 → 0.98`, duration `0.1`. Use `whileTap`.
- **Layout shifts:** `layout` prop with the luxe easing. Never spring on layout — it feels toy-like.
- Use `useReducedMotion()` and short-circuit to opacity-only transitions when true.
- Use `viewport={{ once: true, margin: "-10%" }}` for scroll-triggered reveals so they don't replay.
- Avoid: bouncy springs, rotation, infinite loops, parallax on small viewports, anything decorative under 200ms.

## Modern luxury checklist

A view is ready to ship when:

- [ ] One focal element per screen, clearly the largest thing.
- [ ] Type scale uses tokens; no arbitrary pixel sizes.
- [ ] All spacing snaps to the 8px grid.
- [ ] Palette is ink + warm white + at most one accent.
- [ ] Motion uses `ease-luxe` and stays under 800ms.
- [ ] Works at 375px wide with no horizontal scroll.
- [ ] Tap targets ≥44px on mobile.
- [ ] No drop shadows heavier than `shadow-elevated`.
- [ ] No emoji in UI copy unless the user explicitly asked.

## Anti-patterns — avoid the "generic AI" look

Reject these on sight, even if technically functional:

- Purple→pink→blue gradients on hero backgrounds or buttons.
- Glassmorphism cards stacked over a blurred gradient blob.
- Tilted 3D cards, mouse-tracked spotlight effects on every section.
- Generic stock-style icons inside circle-gradient backgrounds.
- Emoji used as feature-section icons (✨ 🚀 🎯).
- "Bento grid" of unrelated content as a substitute for narrative structure.
- Auto-generated faux-testimonial cards with placeholder avatars.
- Headlines like "Supercharge your workflow" or "AI-powered everything."
- More than one CTA color. More than two CTAs visible at once.
- Looping background animations (gradient meshes, animated noise).
- Centering everything by default. Asymmetry and grid offsets read more considered.
- Rounded-full buttons on desktop hero CTAs — use `rounded-sm` or `rounded-md`.

When in doubt: remove an element, tighten the copy, increase the type size, and look again.
